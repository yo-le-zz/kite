kite

Compilateur & CLI multiplateforme. Une commande, et c'est installé.

linux — sh
curl -fsSL https://kite-lang.pages.dev/install.sh | sh

Installe dans ~/.local/bin. Nécessite curl et tar.

  • install-macos.sh — script brut, pour macOS
  • install.ps1 — script brut, pour Windows
  • Releases GitHub — .deb, .zip, binaires bruts pour chaque OS/architecture
