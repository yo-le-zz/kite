kite

Lisible comme Python, rapide comme C. Une commande, et c'est installé. v0.3.0

linux — sh
curl -fsSL https://kite-lang.pages.dev/install.sh | sh

Installe dans ~/.local/bin. Nécessite curl et tar.

Autres méthodes

  • install.sh — script brut, pour Linux
  • install-macos.sh — script brut, pour macOS
  • install.ps1 — script brut, pour Windows
  • Releases GitHub — .deb (amd64, arm64), .tar.gz / .zip Linux, macOS, Windows (x64, arm64), checksums.txt
  • Debian / Ubuntu : curl -fsSL https://kite-lang.pages.dev/install.sh | sh -s -- --deb

Premier programme

make main():
    name = "Kite"
    print(f"Hello, {name}!")

Enregistre ça dans src/main.ki, puis kite run. Kite a besoin de clang pour produire un exécutable natif.

Le compilateur s'écrit lui-même

Kite est en cours de réécriture en Kite : le lexer et le parser tournent déjà en Kite et produisent des résultats identiques au compilateur Rust d'origine (conservé comme « stage0 »). Voir docs/bootstrap.md.
